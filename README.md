# Сайт учителя начальных классов

Персональный сайт Шумиловой Дарьи Александровны для родителей и учеников.
Чистые HTML, CSS и JS без сборки. Содержимое меняется в админке `admin.html`.

## Что где лежит

| Файл / папка | Зачем |
|---|---|
| `index.html` | сайт |
| `admin.html` | админка (вход по e-mail и паролю) |
| `config.js` | адрес базы Supabase и публичный ключ |
| `content/default.json` | всё содержимое сайта и резервная копия |
| `assets/css`, `assets/js` | стили и скрипты |
| `assets/fonts` | Playfair Display и Manrope (кириллица и латиница), локально |
| `assets/vendor/supabase.js` | библиотека supabase-js 2.45.4 (UMD), локально |
| `assets/img`, `assets/media` | фото учителя, сканы грамот, фото и видео альбома «Подготовка к школе» |
| `supabase/setup.sql` | настройка базы одним скриптом |
| `tests/run-tests.js` | автотесты (Playwright, Supabase имитируется) |

## Посмотреть у себя на компьютере

Нужен Node.js. В папке проекта:

```bash
node tests/serve.js 8080
```

Сайт: http://localhost:8080/, админка: http://localhost:8080/admin.html.
Пока `config.js` не заполнен, админка работает в демо-режиме: правки хранятся только в этом браузере.

## Запуск в интернете

1. **Supabase.** Зарегистрируйтесь на supabase.com, New project. Откройте SQL Editor, вставьте весь файл `supabase/setup.sql` и нажмите Run.
2. **Пользователь.** Authentication → Users → Add user → Create new user. Введите e-mail и пароль, отметьте Auto Confirm User.
3. **Права администратора.** В SQL Editor выполните (со своим e-mail):
   ```sql
   insert into public.admins (user_id) select id from auth.users where email = 'почта@example.ru';
   ```
4. **Закрыть регистрацию.** Authentication → Sign In / Providers: выключите «Allow new users to sign up».
5. **Ключи.** Project Settings → API (или Data API / API Keys). Скопируйте Project URL и ключ **anon** или **publishable** (`sb_publishable_…`) в `config.js`:
   ```js
   supabaseUrl: 'https://xxxx.supabase.co',
   supabaseKey: 'sb_publishable_...'
   ```
   Ключ `service_role` / `sb_secret_…` в `config.js` **не вписывать никогда**.
6. **GitHub Pages.** Создайте публичный репозиторий. Загрузите **содержимое** этой папки (файлы `index.html`, `admin.html` и т. д. должны оказаться в корне репозитория, а не внутри папки). Папку `node_modules` загружать не нужно. Settings → Pages → Deploy from a branch → `main` / `(root)` → Save. Через 1 или 2 минуты сайт откроется по адресу `https://имя.github.io/репозиторий/`. Если сборка не началась, сделайте любой новый коммит (например, поправьте README).
7. **Адрес сайта в Supabase.** Authentication → URL Configuration → Site URL = адрес сайта. В Redirect URLs добавьте адрес админки `https://имя.github.io/репозиторий/admin.html` (нужно для «Забыли пароль»).
8. **Первое сохранение.** Откройте `admin.html`, войдите и нажмите «Сохранить». Содержимое запишется в базу.

## Как работает

* Сайт сначала берёт содержимое из Supabase (ждёт до 5 секунд). Если база недоступна, показывает `content/default.json`.
* Для ключей `sb_publishable_` сайт отправляет ключ только в заголовке `apikey`.
* Фото при загрузке сжимаются до 1800 пикселей. «Настроить кадр» не обрезает файл, а запоминает точку и масштаб `{x, y, z}`.
* Видео загружаются как есть, до 50 МБ (ограничение бесплатного Supabase). Обложка создаётся автоматически. Для видео можно задать начало и конец показа («Обрезать по времени»).
* Пустые поля и пустые блоки на сайте не показываются. Пустые альбомы показываются с описанием и пометкой «Скоро здесь появятся фотографии».
* Всё, что ввели в админке, выводится как текст (защита от XSS). Ссылки разрешены только `http(s)`, `mailto:`, `tel:` и относительные.

## Админка коротко

* **Страница → Шапка:** имя, эпиграф, фото в круге, кнопки, три карточки.
* **Страница → Блоки страницы:** порядок, скрыть, удалить (стандартный блок можно вернуть), «Новый блок».
* **Содержимое:** каждый раздел сайта. Редкие поля спрятаны под «Дополнительно».
* **Настройки → Копия и пароль:** скачать или загрузить `content.json`, проверить новые материалы, сменить пароль.
* Сохранение: кнопка «Сохранить» или Ctrl+S. Если уйти со страницы с несохранёнными правками, браузер предупредит.

### Если обновили проект

Если в `content/default.json` добавили новые материалы, а в базе уже лежит старое содержимое, админка сама покажет «В проекте появились новые материалы» и предложит добавить их. Правки учителя при этом не теряются. Удалённое учителем повторно не предлагается.

## План Б: Supabase недоступен

Бесплатный Supabase в России иногда не открывается без VPN. Проверьте сайт с Wi-Fi и с мобильного интернета.
Если база не открывается, можно хранить содержимое прямо в репозитории GitHub:

1. GitHub → Settings → Developer settings → Fine-grained tokens → Generate new token. Repository access: только репозиторий сайта. Permissions → Contents: Read and write.
2. В `config.js` оставьте `supabaseUrl` пустым и заполните `github: { owner: 'имя', repo: 'репозиторий', branch: 'main' }`.
3. В админке войдите с этим токеном. «Сохранить» записывает `content/default.json` в репозиторий, фото и видео попадают в `assets/uploads`. Сайт обновляется сам примерно через минуту.

Токен даёт право менять сайт: никому его не пересылайте.

## Важно

* Фото и видео детей публикуйте только с письменного согласия родителей.
* Не публикуйте документы с персональными данными других людей (списки награждённых и т. п.). Например, из приказа о ГТО на сайт взяты только титульная страница и скрин знака, страница со списком фамилий не выложена.
* Бесплатный Supabase «засыпает» после недели без обращений. Сайт в это время покажет копию из `content/default.json`. Время от времени скачивайте `content.json` в админке и заменяйте им `content/default.json` в репозитории, чтобы копия была свежей.

## Тесты

```bash
npm install
npx playwright install chromium
npm test
```

Проверяется: отрисовка, фильтр достижений и лайтбокс, порядок фото и видео, мобильная версия, отсутствие длинных тире, пустые поля, XSS, отказ и зависание базы, работа без внешнего интернета, вход и права, «Забыли пароль» и смена пароля, правка с загрузкой фото и кадром, загрузка видео в альбом, блоки, слияние новых материалов, предупреждение о несохранённых правках, экспорт и импорт, демо-режим, мобильная админка.
